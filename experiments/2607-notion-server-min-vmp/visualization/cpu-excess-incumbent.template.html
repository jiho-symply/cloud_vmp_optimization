시나리오별 자원 압력과 2nd-stage 대응
행은 시나리오, 열은 30분 슬롯이며 각 칸은 세 서버 중 최대값이다. CPU·메모리는 Spot preemption 이후 값이고, hover하면 preemption 전후와 제외된 Spot 부하가 표시된다. Batch 비율은 해당 슬롯에 처리한 작업량이 하루 전체 필요 작업량에서 차지하는 비율이다.

1st-stage에 배치한 VM 크기와 서버 용량 비교
시나리오가 정해지기 전에 각 서버에 배치한 On-demand VM과 admission된 Spot VM의 configured CPU·메모리 크기를 더한 값이다. 100%는 서버 한 대의 물리용량이며 100%를 넘으면 configured size 기준 overcommit이다. 실제 usage와 Batch allocation은 포함하지 않는다. 이 incumbent의 최대값이 218%라 막대를 자르지 않도록 그래프는 220%까지 확보하되, 눈금은 0%, 100%, 200%만 표시한다.

서버별 실제 On-demand served, Spot served, Batch allocation은 100% 물리용량 안에 쌓아 표시한다. 그 위의 진홍색 막대는 On-demand CPU 초과 부하이며, 막대 높이가 초과율에 비례한다. 이는 물리용량을 넘겨 배치한 부하가 아니라 2nd-stage recourse다.
